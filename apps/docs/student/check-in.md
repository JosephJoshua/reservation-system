# 到场签到

到达场馆后，请扫描前台的签到码完成签到。签到用于记录出勤，不会再次扣费或扣课时。

## 扫码签到

1. 开课前 30 分钟起，打开小程序的“课程”页，顶部会出现即将开始的课程和“扫码签到”按钮。
2. 点击“扫码签到”，扫描前台张贴的签到码。
3. 页面显示“签到成功”即完成。

您也可以在“预约详情”中点击“签到”一行进行扫码。如果使用微信的“扫一扫”扫描签到码，请按页面提示打开小程序签到。

::: info 无法扫码时
- 如果提示“这不是场馆的签到码”，请确认扫描的是前台张贴的签到码。
- 如果手机不便操作，请告知前台或教练，他们可以为您记录到课。
- 场馆可能关闭扫码签到，此时由前台或教练记录。
:::

## 出勤状态

签到或记录出勤后，“课程”页和“预约详情”会显示出勤情况，上课期间即可看到：

| 状态 | 含义 |
| --- | --- |
| 已签到 / 已到课 | 您已到场上课 |
| 缺席 | 前台或教练记为未到场，或课程结束时仍未签到。缺席照常计课，不退费用，也不退回课时 |

如果出勤记录有误，请联系前台更正。
