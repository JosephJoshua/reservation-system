# 改约与取消

<Clip phone src="video/mp-move-cancel.mp4" title="选择改约的新时间，以及取消预约" />

## 改约

在免费取消截止前，您可以把课程改到其他时间，无需先取消再重新预约。

1. 打开“课程”页，点击要调整的课程，进入“预约详情”。
2. 点击底部的“改约”。
3. 在“改约”页面中选择新的日期和时段。如果有多位教练可选，也可以更换教练。
4. 确认底部显示的新时间无误后，点击“确认改约”。

改约后，原时段会释放给其他学员，已付的款项和课时不变。

::: info 改约次数
默认每节课可自行改约 1 次，且须在免费取消截止前操作（以场馆设置为准）。“预约详情”页面会提示您还可以改约几次。次数用完或已过截止时间时，如需调整请联系场馆。
:::

## 取消预约

1. 打开“课程”页，点击要取消的课程。
2. 点击“取消预约”，阅读弹窗中的说明后点击“确认取消”。

  <Shot phone src="img/mp/s14-detail-cancelled.webp" alt="已取消的预约" />

取消的结果取决于取消时间：

| 取消时间 | 微信支付的课程 | 使用课时包的课程 |
| --- | --- | --- |
| 免费取消截止前（默认为开课前 24 小时） | 全额原路退回 | 课时退回课时包 |
| 免费取消截止后、开课前 | 默认不退款 | 默认不退回课时 |
| 课程开始后 | 无法取消 | 无法取消 |

“预约详情”页面的“免费取消截止”一行显示本节课的截止时间。超过截止时间取消时，弹窗会提前说明这次取消不会退款或退回课时，请确认后再操作。具体规则以该页面的说明为准。

::: tip 场馆或教练调整了您的课程
如果场馆或教练取消了您的课程，已付款项全额退回，课时退回课时包，“预约详情”中会显示取消原因。如果是场馆或教练改约，且改约发生在临近开课时，您在开课前仍可免费取消。订阅了“课程变动”通知的学员会收到微信服务通知。

如果您的课程时间遇到场馆闭馆、教练请假，或教练已停止授课，这节课无法按原计划上课，请不要到场，也无法扫码签到。“课程”页会显示“场馆闭馆”“教练请假”或“教练停课”，“预约详情”页面会注明原因。在场馆处理之前，您可以在开课前随时免费取消或改约。
:::

## 未完成支付的预约

选择微信支付但尚未付款的预约，在“课程”页显示为“待支付”。打开后可以点击“去支付”继续付款，或点击“取消预约”放弃。超过支付时限未付款的预约会自动失效。如果这段时间内场馆闭馆、教练请假或教练停止授课，“课程”页会显示“场馆闭馆”“教练请假”或“教练停课”，“预约详情”页面显示“课程有变”并注明原因，预约将无法继续支付，请取消后重新预约；已经付款的，款项会自动全额原路退回，“预约详情”页面会显示原因和退款进度。超过支付时限后才完成付款、而这个时间已被他人预约的，款项同样自动退回。

## 重新预约

已取消或已失效的预约，打开后可以点击“重新预约”，快速回到这门课的选择时间页面。
