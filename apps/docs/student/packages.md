# 购买课时包

课时包是一次购买多节课，单节价格通常比单次付费更优惠。购买后，预约时可直接选择“使用课时包”。

## 购买

1. 在“预约”页点击“购买课时包”，或在“我的”页点击“购买课时包”。
2. 查看各课时包的适用课程、适用教练、节数、有效期和价格。标有“限时优惠”的课时包正在打折。
3. 首次购买时，请勾选同意用户协议和隐私政策。
4. 点击“购买”，确认金额后完成微信支付。支付成功后会自动打开“我的课时包”。

<Shot phone src="img/mp/s15-packages.webp" alt="课时包列表" />

::: info 使用规则
- 课时包仅限本人使用，不能转让。
- 有效期从购买当天起计算。过期后剩余课时失效，请留意到期时间。到期前 7 天，如果您订阅了通知，会收到到期提醒。
- 部分课时包只适用于指定教练，购买前请查看“适用教练”。
:::

## 查看我的课时包

在“我的”页点击“我的课时包”，可以查看每个课时包的剩余节数、有效期和状态。

<Shot phone src="img/mp/s16-my-packages.webp" alt="我的课时包" />

预约时使用课时包会立即扣除 1 节；在免费取消截止前取消，课时会退回。

## 申请退款

未使用的课时可以申请退款，由场馆审核。

1. 在“我的课时包”中找到要退的课时包，点击“申请退款”。
2. 阅读提示中的退款金额计算方式后，点击“提交申请”。

退款金额为实付金额扣除已上课时的单节价（按授课教练的价格计算）。申请后，该课时包暂停使用。场馆同意后：

- 微信支付的款项原路退回；
- 在前台付款的，请到前台领取退款。

::: warning 申请前请先取消使用这个课时包的预约
如果课时包还有尚未上的预约，需要先取消这些预约，才能申请退款。
:::
