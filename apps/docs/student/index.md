# 开始使用

学员通过微信小程序“Lumi乒乓”预约课程。小程序无需下载安装，也无需注册，首次打开时使用微信身份自动登录。

## 打开小程序

1. 在微信顶部的搜索框中输入“Lumi乒乓”，选择小程序；或扫描场馆提供的小程序码。
2. 首次使用时，小程序可能弹出微信的隐私授权提示。请阅读后点击“同意”，否则部分功能（例如扫码签到、添加到日历）无法使用。

小程序底部有三个标签页：

| 标签页 | 用途 |
| --- | --- |
| 预约 | 首页。查看场馆公告、选择课程、了解教练、购买课时包、查看场馆地址和电话 |
| 课程 | 您预约的课程，分为“即将开始”和“已结束”两栏 |
| 我的 | 个人信息、课时包、学习记录、发票、联系客服、外观等 |

## 首次预约前需要做什么

首次预约或购买课时包时，确认页面会请您：

- 填写**上课学员的姓名和手机号**。这两项仅场馆工作人员可见，用于上课联系和课程变动通知。如果为孩子预约，请填写孩子的姓名。
- 勾选同意**用户协议**和**隐私政策**。

填写一次后会自动保存，之后预约无需重复填写。如需修改，请见[个人信息与账号](./account)。

::: tip 曾在前台办理过课时包？
如果您在使用小程序之前已在前台登记或购买过课时包，请先向前台索取绑定码，在“我的 > 同步前台记录”中输入，您的课时包和预约记录会同步到小程序。详见[同步前台记录](./account#同步前台记录)。
:::
