# 申请发票

已支付的订单（单次课或课时包）可以申请电子发票。发票由场馆开具，开具后会发送到您填写的邮箱，也可以在小程序中查看。

## 提交申请

1. 在“我的”页点击“发票”，列表中显示可开票的订单。也可以在“预约详情”或“我的课时包”中点击“申请开票”。
2. 点击要开票的订单，进入“申请发票”页面。
3. 选择抬头类型：
   - **个人**：填写个人姓名；
   - **单位**：填写单位名称（与营业执照一致）和税号（纳税人识别号）。
4. 填写接收发票的邮箱。
5. 点击“提交申请”。

下次申请时，系统会自动填入本次的抬头和邮箱。

## 查看进度和发票

在“我的 > 发票”中，每个订单会显示开票状态：

| 状态 | 说明 |
| --- | --- |
| 可开票 | 订单已支付，尚未申请 |
| 开票中 | 已提交申请，等待场馆开具 |
| 已开票 | 点击“查看发票”可打开 PDF，同时已发送到邮箱 |
| 未通过 | 场馆退回了申请，页面会显示原因（例如税号有误）。修改后点击“重新申请发票” |

::: info 说明
- 开票金额为实付金额扣除已退款部分。全额退款的订单不能开票。
- 每个订单只能开具一张发票。
:::
