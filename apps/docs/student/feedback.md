# 课后点评

教练会在课后为您撰写点评，记录本节课的练习内容、进步和下次的练习重点，有时还会附上课堂照片。

## 查看一节课的点评

教练发布点评后，如果您订阅了“课后点评”通知，会收到微信服务通知。

1. 打开“课程”页的“已结束”，有点评的课程会显示“有点评”。
2. 点击课程，在“预约详情”中查看点评内容。点击照片可以放大查看和保存。

## 学习记录

在“我的”页点击“学习记录”，可以按时间顺序查看所有课后点评，回顾自己的训练过程。点击任意一条可打开对应课程的详情。

<Shot phone src="img/mp/s18-learning-record.webp" alt="学习记录" />

::: info 说明
- 教练通常在课后 7 天内撰写点评，并非每节课都有点评。
- 教练修改点评后，您会看到更新后的内容，但不会再次收到通知。
- 教练的课堂备注和学员档案仅供场馆内部教学使用，不会展示给学员。
:::
