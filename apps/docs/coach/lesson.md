# 上课与签到

## 课程详情

在“教练工作台”点击一节私教课，进入“课程详情”。页面包含：

- **学员信息**：姓名、电话（点击可直接拨打）、支付方式，以及“与你的第几节课”。电话与学员档案的查看时间相同：仅限已付款的课程，到这节课结束后 7 天内；未付款、已取消或更早的课程不显示电话。
- **学员档案**：水平、握拍、标签和备注，详见[学员档案](./profile)。
- **签到**：记录学员到课或缺席。
- **课后点评**：课后为学员撰写点评，详见[写课后点评](./feedback)。
- **课堂备注**：仅您和场馆可见的教学记录。
- **之前的课**：这位学员在您这里上过的课及当时的备注。
- 底部的“改约”和“取消这节课”，详见[改约与取消](./change)。

## 记录签到

课程开始后，“签到”区域会出现“到课”和“缺席”两个按钮。

1. 学员到场后点击“到课”；课程结束仍未到场的，点击“缺席”。
2. 如果点错，再点一次同一个按钮即可撤销。

::: info 签到说明
- 签到不会影响扣费：课时在学员预约时就已扣除。缺席照常计课，不退费用，也不退回课时。
- 学员也可以扫码自助签到，前台也可以代为签到。已签到的课程会显示是谁记录的。
- 签到有截止时间，过后如需修改，请联系场馆。
- 场馆可能关闭教练点名，此时签到由前台办理，页面会显示“签到由前台办理”。
- 只有记为“到课”的课程才能撰写课后点评。
:::

## 小班课点名

在“教练工作台”点击小班课，进入学员名单：

1. 课程开始后，每位学员右侧都有“到课”和“缺席”按钮，逐一点击即可。
2. 如果大部分学员都已到场，可点击底部的“未签到的全部记为到课”。
3. 点击学员姓名，可以为这位学员写课堂备注和课后点评。

<Shot phone src="img/mp/c10-session.webp" alt="小班课名单" />

小班课的名单调整和取消由场馆负责，如有需要请联系前台。

## 课堂备注

在“课程详情”的“课堂备注”中记录本节课练了什么、下次注意什么。输入后点击“保存”，或离开输入框时自动保存。

课堂备注**仅您和场馆可见**，学员看不到。下次上课时，可以在“之前的课”中看到这些备注。
