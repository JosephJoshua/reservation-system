# 改约与取消

遇到特殊情况，您可以调整自己的私教课。小班课的调整请联系场馆。

## 改约

1. 在“课程详情”底部点击“改约”。
2. 选择新的日期和时间。只能改到您自己排班内的空闲时间；显示“球台已满”的时间不可选。
3. 点击“确认改约”。

订阅了通知的学员会收到改约消息。**请同时电话告知学员。** 临近开课时由教练改约的课程，学员在开课前仍可免费取消。

## 取消课程

1. 在“课程详情”底部点击“取消这节课”。
2. 填写取消原因（学员可见，例如“教练生病”），点击“下一步”。
3. 阅读提示后确认取消。

取消后，学员已付的款项全额退回，使用课时包的课时退回课时包。请同时电话告知学员。
