# 查看课表

“教练工作台”按天显示您的课程和空闲时间。

1. 在“我的”页点击“教练工作台”。
2. 左右滑动顶部的日期栏，点击日期查看当天安排。

<Shot phone src="img/mp/c02-workbench.webp" alt="教练工作台的一天" />

列表中的每一行代表一段时间：

| 显示 | 含义 |
| --- | --- |
| 学员姓名和课程 | 已预约的私教课，点击可打开课程详情 |
| 小班课和报名人数 | 小班课，点击可打开学员名单 |
| 空闲，可预约 | 排班内尚未被预约的时间，学员可以预约 |
| 请假 / 闭馆 | 这段时间不开放预约 |

列表顶部汇总当天的课程节数和空闲时长。

::: tip 快速请假
如果场馆允许教练自己排班，点击“空闲”行可以直接为这段时间请假，点击“请假”行可以取消请假。详见[排班、请假与加班](./hours)。
:::

## 课程通知

学员预约、取消或改约您的课程时，如果您已订阅教练通知，会收到微信服务通知。
