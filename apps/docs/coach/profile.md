# 学员档案

学员档案记录学员的水平、握拍、特点和训练目标，所有教练和场馆共同维护。上课前查看档案，可以快速了解一位新学员。

## 查看档案

在“课程详情”中的“学员档案”区域，可以看到：

- 水平、握拍和标签；
- 备注（较长时可点击“展开”）；
- 学员在本馆的上课次数和缺席次数；
- 最后一次修改的人和时间；
- “历次课后点评”：所有教练为这位学员写过的点评。

## 填写或修改档案

1. 在“学员档案”区域点击“填写”或“编辑”。
2. 选择水平（零基础、初级、中级、高级）和握拍（横拍、直拍）。
3. 添加标签：输入后按键盘上的“完成”，例如“反手弱”“备赛”。最多 8 个，每个不超过 10 个字。点击已有标签可删除。
4. 在备注中填写打法特点、训练目标、上课要注意的地方。
5. 点击“保存”。

<Shot phone src="img/mp/c08-profile-edit.webp" alt="编辑学员档案" />

::: warning 请勿记录健康信息
档案仅场馆和教练可见，学员看不到。请勿在档案中记录病史、伤病等健康信息。
:::

::: info 可以查看和修改的时间
您可以查看和修改已付款课程学员的档案，从学员预约起，到这节课结束后 7 天内有效。如果其他教练或场馆刚刚修改过档案，保存时会提示您确认，以免覆盖对方的修改。
:::
