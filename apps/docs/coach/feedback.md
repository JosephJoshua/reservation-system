# 写课后点评

课后点评会展示给学员，帮助学员了解本节课的收获和下次的练习重点。

<Clip phone src="video/mp-coach-feedback.mp4" title="记录到课并发布课后点评" />

## 发布点评

1. 在“教练工作台”打开已上完的课程。学员需已记为“到课”。
2. 点击“写课后点评”。
3. 填写这节课练了什么、哪里有进步、下次练什么，最多 500 字。
4. 如需附上照片，点击“添加”，从相册选择或直接拍照，最多 6 张。点击照片上的编辑图标可以裁剪，点击关闭图标可以移除。
5. 点击“发布”。

发布后，学员会收到微信服务通知（如已订阅），并可以在课程详情和“学习记录”中看到点评和照片。

## 修改或删除

- 在课程详情的“课后点评”区域点击“修改”，修改后点击“保存”。学员会看到新的内容，但不会再次收到通知。
- 在点评编辑页面点击“删除”，可以删除这条点评。

::: info 时限与可见性
- 点评需在课程结束（或记为到课）后 7 天内发布，过期后无法再写。
- 以下情况学员看不到点评：签到被撤销或改为缺席、课程被取消、场馆隐藏了这条点评。课程详情中会显示原因。
- 课后点评对学员可见；课堂备注只有您和场馆可见，二者互不影响。
:::
