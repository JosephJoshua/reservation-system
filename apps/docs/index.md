# Lumi乒乓 使用手册

本手册介绍 Lumi乒乓 预约小程序和管理后台的使用方法。请根据您的身份选择对应的指南。

<div class="audience">
  <a href="./student/">
    <strong>我是学员</strong>
    <span>在小程序中预约课程、购买课时包、改约、签到、查看课后点评和申请发票。</span>
  </a>
  <a href="./coach/">
    <strong>我是教练</strong>
    <span>在小程序的教练工作台查看课表、记录签到、填写学员档案、撰写课后点评和管理排班。</span>
  </a>
  <a href="./admin/">
    <strong>我是前台或管理员</strong>
    <span>在管理后台处理签到、排课、代约、退款、发票和报表，并维护课程、教练与场馆设置。</span>
  </a>
</div>

## 如何打开

| 使用者 | 入口 |
| --- | --- |
| 学员 | 在微信中搜索“Lumi乒乓”小程序，或扫描场馆提供的小程序码 |
| 教练 | 同一个小程序，在“我的”页底部点击“教练入口” |
| 前台和管理员 | 在电脑或手机浏览器中打开场馆网址后加 `/admin/`，使用员工账号登录 |

## 阅读说明

- 手册中的截图来自演示数据，姓名、电话和金额均为虚构，实际页面以您所见为准。
- 文中提到的时限和次数（例如“课前 24 小时可免费取消”）是系统默认值。场馆可以在后台修改，课程也可以单独设置，请以小程序中显示的规则为准。
- 带有“视频”标记的内容是完整操作的录屏，可点击播放。
