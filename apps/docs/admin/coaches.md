# 教练

“教练”页包含“教练”和“教练类别”两个标签。本页需要“管理员”角色；修改排班和请假也可以由“前台”完成，详见[日程](./schedule#修改教练排班)。

<Shot src="img/admin/coaches.webp" alt="教练列表" />

列表显示每位教练的类别、所教课程与价格、在职状态和小程序绑定情况。拖动行首的手柄可以调整教练在小程序中的显示顺序。

## 新建或编辑教练

点击“新建教练”，或点击教练姓名进入编辑页。右侧会实时显示教练主页在小程序中的样子。

<Shot src="img/admin/coach-edit.webp" alt="编辑教练" />

| 字段 | 说明 |
| --- | --- |
| 姓名 | 学员在小程序中看到的名字 |
| 照片 | 支持 JPG、PNG 或 WebP 格式，选择后裁剪为正方形 |
| 类别 | 决定该教练的课程价格和课时费；不选则按课程的标准价收费 |
| 头衔 | 一句话介绍，显示在姓名下方，例如“前省队队员” |
| 擅长 | 最多 6 个标签，每个不超过 10 个字，输入后按回车添加 |
| 所教课程 | 学员只能在这些课程中预约该教练 |
| 介绍 | 比赛成绩、执教经历、教学风格等，显示在教练主页 |
| 在职 | 停用后教练不再出现在小程序中，也无法使用教练工作台，已登录的微信会立即退出。重新启用后，教练再次进入工作台即可 |

::: tip 停用教练前
停用不会自动取消该教练已有的预约。请先在[预约](./bookings)中改约或取消这些课程。停用后，学员可以在开课前随时免费取消或改约这些课程；尚未付款的预约无法继续支付，已付款的将自动全额退回。
:::

## 绑定小程序

教练需要先绑定微信，才能在小程序中使用教练工作台。

1. 在列表的“小程序”一列点击“绑定”，或在编辑页点击“绑定小程序”。
2. 点击“生成绑定码”。绑定码为 8 位，24 小时内有效，只能使用一次。
3. 请教练在小程序“我的”页底部点击“教练入口”，输入绑定码。

<Shot src="img/admin/coach-bind.webp" alt="生成绑定码" />

教练更换微信时，重新生成绑定码并用新微信绑定即可，原微信会自动退出。如需停止某个微信的访问，请点击“解除绑定”。

## 排班

列表中的“排班”用于设置教练的每周可约时间、请假和加班，操作方法与[日程](./schedule#修改教练排班)页相同。

## 教练类别

教练类别用于为不同级别的教练设置不同的价格和课时费，例如“主教练”和“高级教练”。

<Shot src="img/admin/categories.webp" alt="教练类别" />

1. 切换到“教练类别”标签，点击“新建类别”。
2. 填写名称。
3. 在“价格”中为需要单独定价的课程填写价格，未填写的课程按标准价收费。
4. 在“课时费”中填写每节课付给教练的金额，留空即为“未设置”，详见[教练课时费](./coach-pay)。
5. 保存后，在教练的编辑页中选择该类别。

仍有教练属于某个类别时，该类别不能删除。修改价格和课时费会记入[操作记录](./action-log)。
