# 发票

学员在小程序中为已支付的订单申请电子发票。财务在税务系统开具后，把 PDF 上传到后台，学员即可在小程序中查看。本页的操作需要“财务”或“管理员”角色。

<Shot src="img/admin/invoices.webp" alt="发票申请" />

## 开票

1. 在“发票”页筛选“开票中”，查看待处理的申请。列表显示学员、订单、抬头、税号、邮箱和开票金额。
2. 按照抬头、税号和金额在税务系统中开具电子发票，并下载 PDF，同时发送到学员填写的邮箱。
3. 在后台点击“上传发票”，选择 PDF 文件（不超过 10MB），点击“确认开票”。

<Shot src="img/admin/invoice-issue.webp" alt="上传发票" />

开票金额为订单实付金额扣除已退款金额。

## 拒绝申请

抬头或税号有误时，点击“拒绝”并填写原因，例如“税号有误，请核对后重新申请”。学员会在小程序中看到原因，可以修改后重新申请。

## 查看和更换发票

已开票的申请可以点击“查看”打开 PDF。需要更换时点击“重新上传”。

## 开票后发生退款

已开票的订单之后又发生退款时，该申请会出现在“开票后有退款”筛选中。请按退款情况冲红或重新开具发票，处理后点击“退款已处理”。
