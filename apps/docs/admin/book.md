# 代约

学员电话预约、到店预约或不方便使用小程序时，前台可以代为预约。学员不必先打开小程序，可以先[前台建档](./students#前台建档)。

<Clip src="video/admin-book.mp4" title="在日程页为学员代约并使用课时包" />

## 操作步骤

1. 在“日程”“今日”“预约”或学员详情页点击“代约”；也可以在日程上直接点击教练排班中的空白处。
2. **学员**：输入姓名或手机号搜索并选择。找不到时点击右侧的“前台建档”。
3. **课程**：选择要上的课程。
4. **时间**：选择教练（或“全部教练”）和日期，点击可约的开始时间。小班课则选择已排好的场次，并显示剩余名额。
5. **支付**：
   - **课时包**：学员有可用的课时包时显示剩余节数，选择后扣除 1 节；
   - **线下收款**：填写实收金额，选择收款方式（现金、支付宝、微信收款码、转账；每次都需选择，不会预先选好），可以填写备注。填 0 即为免费，无需选择收款方式。
6. 点击“确认代约”。

## 排班外的时间

学员要约的时间不在教练排班内时，点击“排班外的时间”，选择任意开始时间。请先和教练确认。教练已有课、请假或闭馆的时间仍然不能预约。

::: info 说明
- 前台代约的课程与学员自己预约的课程遵循相同的取消和改约规则，学员可以在小程序中看到（已绑定微信的学员）。
- 没有“管理员”角色的员工只能按标价收款；需要优惠时请联系管理员。
- 每次代约都会记入[操作记录](./action-log)。
:::
