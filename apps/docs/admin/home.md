# 首页内容

“首页内容”用于维护小程序首页的轮播图、公告和预约须知。本页需要“管理员”角色。在电脑上，右侧会实时显示首页在小程序中的样子。

<Shot src="img/admin/home-content.webp" alt="首页内容" />

## 轮播图

点击“新建轮播图”，或点击图片进入编辑页。

<Shot src="img/admin/banner-edit.webp" alt="编辑轮播图" />

| 字段 | 说明 |
| --- | --- |
| 图片 | 支持 JPG、PNG 或 WebP 格式，选择后可以裁剪和旋转 |
| 标题 | 显示在图片底部，不填则不显示 |
| 点击跳转 | 学员点击图片后打开的页面，详见下文 |
| 展示时间 | 在指定时间段内展示，不填则一直展示 |
| 展示 | 关闭后暂时隐藏 |

拖动行首的手柄可以调整轮播顺序。

## 首页公告

公告是一句话，显示在轮播图下方，例如节假日安排。可以设置结束时间，到时自动隐藏；留空则不显示公告。公告也可以设置点击跳转。

## 预约须知

预约须知是学员确认预约时可以查看的说明，例如“请提前 10 分钟到场，自备球拍和运动鞋”。学员在“我的”页也可以随时查看。留空则不显示。

修改公告和预约须知后，请点击页面底部的“保存”。

## 点击跳转

轮播图和公告可以跳转到以下页面：

| 类别 | 可选目标 |
| --- | --- |
| 页面 | 购买课时包、我的课时包、我的课程、场馆位置、预约须知 |
| 一对一课程、小班课 | 打开该课程的选择时间页 |
| 教练 | 打开该教练的主页 |
| 课时包 | 打开该课时包的详情 |

已停用的课程、教练或已下架的课时包会在选项中标注。跳转目标被删除后，编辑页会提示“原跳转目标已不存在，请重新选择”。
