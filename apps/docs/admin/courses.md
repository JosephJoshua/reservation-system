# 课程

“课程”是学员可以预约的课程类型，例如一对一私教、体验课或青少年小班课。本页需要“管理员”角色。

<Shot src="img/admin/courses.webp" alt="课程列表" />

列表中的“预约规则”一列显示该课程是按“默认”规则，还是单独设置了若干项。拖动行首的手柄可以调整课程在小程序中的显示顺序。“状态”开关可以直接启用或停用课程，误操作时可在提示中点击“撤销”。

## 新建或编辑课程

点击“新建课程”，或点击课程名称进入编辑页。右侧会实时显示该课程在小程序中的样子。

<Shot src="img/admin/course-edit.webp" alt="编辑课程" />

| 字段 | 说明 |
| --- | --- |
| 名称 | 最多 30 个字，例如“一对一私教” |
| 简介 | 显示在小程序的课程介绍中 |
| 时长 | 15 至 480 分钟，以 15 分钟为单位 |
| 上课人数 | 1 人为一对一课程；多于 1 人为小班课，需要在日程页按节安排，详见[小班课](./group-classes) |
| 最低开班人数 | 仅小班课。到免费取消截止时报名人数不足的，整节课自动取消并退款 |
| 每张球台 | 仅小班课。按报名人数占用球台；留空则整班共用一张球台 |
| 标准价 | 小班课填写每人的价格。教练类别可以单独定价，详见[教练](./coaches#教练类别) |
| 折扣 | 设置限时折扣及起止时间，标准价和类别价都按此折扣计算 |
| 体验课 | 每位学员限约次数（在设置中修改），不能使用课时包，也不能设为小班课 |
| 仅测试学员可见 | 用于真实支付测试，普通学员看不到 |
| 启用 | 停用后学员无法再预约，已有的预约不受影响 |

### 预约规则

编辑页底部的“预约规则”可以为这门课程单独设置可提前预约天数、最晚预约时间、免费取消时限、逾时取消的处理方式和学员改约次数。没有单独设置的项目沿用[设置](./settings#默认预约规则)中的默认预约规则，默认规则修改后也会随之变化。

学员预约时适用当时的规则，之后修改规则不影响已有的预约。

::: warning 有预约后不能修改的内容
为保证历史记录准确，课程一旦有预约或排课，以下内容就不能再修改，如需调整请新建课程：
- 时长；
- 是否为体验课；
- 一对一与小班课之间的切换。

已有课时包的课程也不能改为体验课。
:::

## 预览

列表中的“预览”会显示该课程在小程序中的选择时间页，方便确认价格和介绍。
