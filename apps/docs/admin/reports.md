# 概览与报表

“报表”页有“经营分析”和“月报与课时费”两个标签。本页需要“财务”或“管理员”角色。

## 经营分析

选择统计范围（近 7 天、近 30 天、近 90 天、本月、上月、今年，或自定义日期），查看场馆的经营情况。

<Shot src="img/admin/stats.webp" alt="经营分析" />

| 指标 | 说明 |
| --- | --- |
| 净收款 | 期间内的收款减去退款 |
| 课消 | 已上的课和逾时取消的课的价值，课时包按单节均价计算 |
| 上课 | 已结束的课程节数，小班课每节算一节 |
| 上课学员 | 期间内上过课的学员人数，其中新学员指第一次上课的学员 |
| 到课率 | 到课的比例，并显示缺席和未签到次数 |
| 续费率 | 用完或到期的课时包中，学员又续买的比例 |

下方的图表依次为：收入趋势、上课节数、上课学员、教练排班占用、热门时段、课时包销售、预收未上课时和小班课满班率。每张图都可以在“图表”和“数据”之间切换，“数据”以表格显示具体数字。

### 沉睡学员

页面底部列出有剩余课时、但较长时间既没上课也没有预约的学员，方便前台回访。这个列表不受上方日期筛选的影响。

## 月报

在“月报与课时费”标签中选择月份，可以查看：

- **收入**：微信支付、线下收款，其中单次课、体验课、课时包各多少，以及退款和净收入；
- **收入构成**：按付款时间统计，课时包在售出当月计入；
- **未上课时**：当前尚未使用的课时及对应的预收金额；
- **教练课时与课时费**：详见[教练课时费](./coach-pay)。

<Shot src="img/admin/report-month.webp" alt="月报与课时费" />

点击“导出 CSV”可以下载当月的教练课时费明细。
