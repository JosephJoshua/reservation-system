# 教练课时费

系统根据教练类别的课时费标准和已结束的课程，自动计算每位教练每月的课时费。本页需要“财务”或“管理员”角色。

## 设置课时费标准

课时费按“教练类别 × 课程”设置：

1. 打开“教练”页的“教练类别”标签。
2. 编辑类别，在“课时费”中为每门课程填写每节课付给教练的金额。留空即为“未设置”。
3. 保存。

不付课时费的课程请填写 0 元。

在[设置](./settings#课时费)的“课时费”中，可以决定学员缺席、学员逾时取消的课程是否计入课时费。场馆取消的课程不计入；整节取消的小班课也不计入，即使此前有学员逾时取消。小班课每节计一节，与报名人数无关。

## 查看月度课时费

在“报表 > 月报与课时费”中选择月份，“教练课时”表格列出每位教练的已上课时、时长、到课、缺席、未签到、场馆取消、学员逾时取消、计费课时和课时费。点击教练可展开按课程的明细。

## 确认本月

每月结束、且当月开始的课程全部下课后（例如月末最后一晚跨过零点的课程），核对无误即可确认，确认后金额固定：

1. 确认所有课程都已设置课时费。如果有未设置的，页面会提示“还有 N 节课未设课时费”。
2. 点击“确认本月”，核对教练人数和合计金额后确认。

::: info 确认后的变化
- 确认后的金额不再随课时费标准或设置变化。导出预约时，已确认月份的“课时费（元）”列也按确认时记录的金额显示，与月报一致；之后已确认的调整显示在“课时费调整”列，例如“2026-11 调整 -80.00”，尚未确认的调整不显示。
- 之后才补记的签到或取消变动，会作为“调整”计入下一个月。
- 月份需要按顺序确认。
- 管理员可以“撤销确认”最近一个已确认的月份，撤销后金额按当前数据重新计算，需要重新确认。
:::
