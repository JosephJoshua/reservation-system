# 今日签到

“今日”页是前台的工作台：列出今天每位学员的每节课，可以一键签到，也可以在这里代约和建档。

## 为学员签到

1. 学员到场后，在搜索框中输入学员姓名、手机号或教练姓名找到对应的课程。
2. 点击“签到”。课程开始后学员仍未到场的，可以点击“缺席”。
3. 签错时点击“撤销”。

列表顶部的“全部 / 未签到 / 已签到”可以筛选，并显示今日总人次和已到人数。“签到”列会显示由谁记录：前台（含员工姓名）、教练或学员扫码。

::: info 签到规则
- 课前 30 分钟起可以签到，课程开始后可以记缺席。
- 签到只是出勤记录，不涉及扣费：课时在预约时已扣除，缺席照常计课。
- 前台记录的签到，教练不能在小程序中修改或撤销；如需更改，请由前台处理。学员已扫码或教练已记录的到课，前台再次记为到课（例如在预约列表中）后即改为前台记录。
- 已取消整节的小班课不会出现在列表中，学员也不能扫码签到。
- 教练的课时费可能与缺席有关，详见[教练课时费](./coach-pay)。
- 只有记为“到课”的课程，教练才能撰写课后点评。
:::

更早日期的签到可以在[预约](./bookings)列表的“签到”列中修改。

## 签到码

学员可以用小程序扫码自助签到。点击“签到码”，再点击“打印”，把签到码张贴在前台。这个签到码长期有效，适用于所有课程。

<Shot src="img/admin/today-qr.webp" alt="签到码" />

学员扫码签到可以在[设置](./settings#签到)中关闭。关闭后，“签到码”窗口会提示扫码签到已关闭；只有管理员可以在设置中重新开启。

## 代约和前台建档

“今日”页右上角的“代约”和“前台建档”与其他页面的同名按钮相同，详见[代约](./book)和[前台建档](./students#前台建档)。
