# 员工与权限

每位员工使用自己的账号登录。角色决定员工能看到和操作哪些内容。本页的操作需要“管理员”角色。

<Shot src="img/admin/staff.webp" alt="员工列表" />

## 角色

| 角色 | 可以使用的功能 |
| --- | --- |
| 管理员 | 全部功能，包括员工、设置、价格和操作记录 |
| 前台 | 日程、今日签到、预约、学员、排课、代约、前台建档、线下售卖课时包 |
| 财务 | 订单、退款、发票、报表和导出，以及查看预约和学员 |

一位员工可以同时拥有多个角色，权限取并集。例如前台兼收银，可以同时勾选“前台”和“财务”。

::: info 改价限制
没有“管理员”角色的员工，在代约和线下售卖课时包时只能按标价（限时优惠期间为优惠价）收款，不能修改金额，也不能售卖已下架的课时包。
:::

## 新增员工

1. 在“员工”页点击“新增员工”。
2. 填写姓名、登录名（3 到 20 位，可以使用字母、数字和 `_ . -`）和初始密码（8 到 100 位，不能以空格开头或结尾）。
3. 勾选角色，点击“添加”。
4. 把登录名和初始密码告知对方，并请其登录后修改密码。

## 修改员工

在员工所在行可以：

- **改名**：修改显示的姓名；
- **角色**：修改角色，对方下次操作时生效；
- **重置密码**：设置新密码，对方已登录的设备都会退出登录；
- **停用**：对方立即退出且不能再登录，已打开的页面会提示“账号已停用”，操作记录会保留。停用后可以再次启用，对方需要重新登录。

您不能修改自己的角色。系统中至少需要保留一位启用的管理员。

## 修改我的密码

所有角色都可以修改自己的密码：点击页面右上角的账号按钮（显示您的姓名），选择“修改我的密码”，输入当前密码和两次新密码。修改后，您在其他设备上需要重新登录。
