# 订单与退款

本页的操作需要“财务”或“管理员”角色。

## 订单

“订单”页列出所有付款记录，包括学员在小程序中的微信支付，以及前台代约和售卖课时包时的线下收款。

<Shot src="img/admin/orders.webp" alt="订单" />

- 按下单日期、状态、类型（单次课、体验课、课时包）和支付方式筛选，或搜索学员；
- “金额”列显示已退金额；
- 点击学员姓名打开学员详情；
- 点击“导出”下载 CSV，用于对账。

## 退款

退款有以下几种来源：

- 学员在免费取消截止前取消微信支付的课程：**自动原路退款**，无需处理；
- 场馆或教练取消课程、小班课人数不足自动取消：**自动全额退款**；
- 学员申请退还课时包：**需要审核**；
- 前台收款的订单需要退款：**需要当面退还后确认**。

<Shot src="img/admin/refunds.webp" alt="退款" />

### 审核课时包退款

1. 在“退款”页筛选“待审核”，或从“概览”的待办进入。
2. 核对学员、课时包剩余节数和实付金额。“金额”列显示建议退款金额。
3. 点击“同意”，确认或修改退款金额后点击“确认退款”；或点击“拒绝”，填写拒绝原因（学员可见）。

<Shot src="img/admin/refund-approve.webp" alt="同意退款" />

建议金额 = 实付金额 − 已上课时按所上教练的单次价合计。同意后，款项原路退回学员的微信，课时包作废。

如果这笔订单已经开票或正在申请开票，列表中会提示，请同时处理[发票](./invoices)。

### 线下退还

前台付款的订单不能原路退回。这类退款显示为“待提交/待退还”：

1. 把款项当面退还给学员。
2. 在列表中点击“已退还”并确认。

### 退款失败

微信支付退款失败时（例如商户余额不足），退款会显示在“退款失败”中。问题解决后点击“重试”。

| 状态 | 说明 |
| --- | --- |
| 待审核 | 学员申请的课时包退款，等待处理 |
| 待提交/待退还 | 前台付款的退款，等待当面退还 |
| 退款中 | 已提交微信支付，等待到账 |
| 已退款 | 退款完成 |
| 退款失败 | 微信支付退款没有成功，可重试 |
| 已拒绝 | 已拒绝学员的申请 |
