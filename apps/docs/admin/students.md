# 学员

## 学员列表

“学员”页列出所有学员，显示编号、手机号和加入时间。选择“课时包即将到期”筛选时，还会显示课时包、剩余课时、到期日和到期提醒。

<Shot src="img/admin/students.webp" alt="学员列表" />

- 在搜索框中输入姓名、手机号或编号即时查找，手机号中带空格、短横线或 +86 也能找到；也可以在任意页面顶部的“找学员”中搜索。
- 使用筛选查看特定学员：

| 筛选 | 用途 |
| --- | --- |
| 有剩余课时 | 有可用课时的学员 |
| 课时包即将到期 | 30 天内到期且仍有剩余课时的学员，按到期日排序。“到期提醒”列显示是否已发送提醒 |
| 未绑定微信 | 前台建档但尚未同步到小程序的学员 |
| 测试学员 | 用于真实支付测试的账号 |
| 已注销 | 已注销账号的学员，个人信息已删除 |

::: tip 识别同名或同号学员
两位学员的手机号相同时，列表中会标注“手机号重复”。请以**学员编号**区分，学员可以在小程序“我的”页顶部看到自己的编号。
:::

## 学员详情

点击学员姓名打开学员详情，包含以下标签：

- **概况**：剩余课时、下次上课、已上课次数和缺席次数，以及学员档案。没有“课后点评”标签的员工（如财务）会在这里看到最近的课后点评；
- **课时包**：学员的课时包和使用记录；
- **预约**：全部预约记录；
- **课后点评**：教练为这位学员写的全部点评；
- **订单**：付款和退款记录。

<Shot src="img/admin/student-detail.webp" alt="学员详情" />

右上角的“代约”和“前台售卖”用于为这位学员预约和售卖课时包。

### 修改姓名和手机号

有“前台”或“管理员”角色的员工可以点击手机号旁的“修改姓名和手机号”，修改后点击“保存”。学员在小程序中也可以修改自己的姓名和手机号：如果学员在您编辑期间修改过，保存时会提示，并载入学员最新的内容，请核对后再保存。新手机号已属于其他学员时，系统会提醒，确认不是同一人后可以点击“仍然保存”。

## 学员档案

学员档案记录水平、握拍、标签和备注，教练在小程序中可以查看和修改，场馆也可以在这里修改。学员看不到档案。

1. 在学员详情的“学员档案”中点击“编辑”。
2. 选择水平和握拍，添加标签（按回车添加，最多 8 个），填写备注。
3. 点击“保存”。

<Shot src="img/admin/student-profile.webp" alt="编辑学员档案" />

::: warning
请勿在档案中记录病史等健康信息。
:::

## 前台建档

学员第一次来店、尚未使用小程序时，可以先建档，再为其代约或售卖课时包。

<Clip src="video/admin-desk-student.mp4" title="前台建档" />

1. 在“学员”“今日”页或代约窗口中点击“前台建档”。
2. 填写姓名和 11 位手机号（粘贴带空格或 +86 的号码也可以，系统会自动整理）。登记前请先告知学员。
3. 点击“建档”。

<Shot src="img/admin/desk-student.webp" alt="前台建档" />

如果手机号已属于其他学员，系统会提醒。同一人请直接打开已有学员，不要重复建档；确属不同学员（例如家长为两个孩子登记）时，可以点击“仍然新建”。

### 绑定微信

前台建档的学员可以直接来上课。学员开始使用小程序时，需要把前台的记录同步到其微信：

1. 在学员详情中点击“绑定微信”。
2. 请学员用微信扫描显示的小程序码，或在小程序“我的 > 同步前台记录”中输入 8 位绑定码。
3. 绑定成功后，窗口会显示“已绑定微信”，前台登记的课时包、预约和订单会同步到学员的小程序。

<Shot src="img/admin/bind-code.webp" alt="绑定微信" />

绑定码 24 小时内有效，请只给学员本人。系统不会按手机号自动匹配，以免他人冒用。

## 前台售卖课时包

学员在前台用现金、支付宝、微信收款码或转账购买课时包时：

1. 在学员详情中点击“前台售卖”。
2. 选择课时包，核对实收金额，选择收款方式，可以填写备注。
3. 点击“确认收款”。

<Shot src="img/admin/sell-package.webp" alt="前台售卖课时包" />

没有“管理员”角色的员工只能按标价收款。每次打开窗口都会载入最新的价格；如果确认时价格已调整或课时包已下架，系统会提示并刷新列表，请核对后再确认。

## 赠送课时和延长有效期

在学员详情的“课时包”标签中，每个课时包都有以下操作（需要“管理员”角色）：

- **加课时**：赠送课时，例如因教练请假补课。需填写原因。
- **延期**：延长有效期天数，可以填写原因（选填）。
- **记录**：查看这个课时包的购买、使用、退回、赠送和延期记录。

## 删除学员

尚未绑定微信的前台建档学员要求删除个人信息时，管理员可以在学员详情中点击“删除学员”。删除后，姓名、手机号和学员档案会被清除，订单和上课记录会匿名保留。

已绑定微信的学员请在小程序中自行注销，详见学员手册的[注销账号](../student/account#注销账号)。

## 测试学员

在学员详情中打开“测试学员”开关（需要“管理员”角色）后，该学员可以看到设为“仅测试学员可见”的课程，用于上线前的真实支付测试。
