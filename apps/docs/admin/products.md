# 课时包

课时包是学员预先购买的若干节课，预约时可直接抵扣，无需每次付款。本页需要“管理员”角色。

<Shot src="img/admin/products.webp" alt="课时包列表" />

拖动行首的手柄可以调整课时包在小程序中的显示顺序。“状态”开关可以直接上架或下架。

## 新建或编辑课时包

点击“新建课时包”，或点击名称进入编辑页。

<Shot src="img/admin/product-edit.webp" alt="编辑课时包" />

| 字段 | 说明 |
| --- | --- |
| 名称 | 例如“私教 10 次卡” |
| 说明 | 显示在小程序的课时包详情中 |
| 课程 | 课时包只能用于预约这门课程。体验课不能做成课时包 |
| 适用教练 | 不选则教这门课程的所有教练都可以使用；也可以点击按钮一次添加某个类别的全部教练 |
| 课时数 | 1 至 200 节 |
| 价格 | 学员购买时支付的金额 |
| 有效期 | 从购买当天起计算的天数，过期后剩余课时不能再使用 |
| 限时价 | 在指定时间段内以较低价格出售 |
| 在售 | 下架后学员无法再购买，已购买的课时包不受影响 |

学员购买时，系统按当时的课程、课时数、有效期和适用教练生成课时包，之后修改这些内容不会影响已售出的课时包。有学员正在支付某个课时包时，暂时不能修改其课程、课时数、有效期和适用教练，请几分钟后再试。

前台也可以为学员线下售卖课时包，详见[学员](./students#前台售卖课时包)。
