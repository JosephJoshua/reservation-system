# 设置

“设置”页集中管理场馆信息和全局规则。本页需要“管理员”角色。左侧的分区目录可以快速跳转到各部分，有未保存修改的分区会显示圆点。修改后请点击页面底部的“保存”。

## 场馆

<Shot src="img/admin/settings-venue.webp" alt="场馆信息" />

填写场馆名称、地址、电话和营业时间，这些信息会显示在小程序中。电话可以写分机号（如“010-6234 5678 转 8”），两个号码用“/”隔开，末尾可加括号备注（如“（微信同号）”）。学员在小程序点“联系场馆”时拨打第一个号码。

**地图坐标**：在高德、腾讯或百度地图中打开场馆，点击“分享”并复制链接，粘贴到输入框即可自动识别位置；也可以直接填写纬度和经度，或在腾讯地图中搜索选点。学员点击场馆地址时，会按这个位置导航。

## 默认预约规则

<Shot src="img/admin/settings-booking.webp" alt="默认预约规则" />

| 规则 | 说明 | 默认值 |
| --- | --- | --- |
| 可提前预约 | 学员可以预约从今天起多少天内的课程 | 14 天 |
| 最晚预约 | 距离开课不足这个时间时，不能再预约 | 开课前 2 小时 |
| 免费取消 | 开课前超过这个时间取消的，全额退款或退回课时 | 开课前 24 小时 |
| 晚于此时取消 | 视为已上课（不退款、不退回课时），或按比例退款。用课时包预约的课程，只有比例为 100% 时才退回课时 | 视为已上课 |
| 学员改约 | 免费取消截止前，学员每节课可以自行改约的次数；填 0 则不允许改约 | 1 次 |

页面上方会列出单独设置了规则的课程。课程没有单独设置的规则都按这里的默认值，详见[课程](./courses#预约规则)。

**球台数**：同一时间最多能上几节课，留空则不限。小班课按“每张球台”的设置占用球台。

## 排班

<Shot src="img/admin/settings-schedule.webp" alt="排班设置" />

| 设置 | 说明 |
| --- | --- |
| 开始时间间隔 | 学员可选的上课开始时间，从整点起每隔 15 分钟、30 分钟或 1 小时一个 |
| 课间休息 | 同一教练两节课之间至少空出的时间，0 至 60 分钟 |
| 教练自己排班 | 关闭后，教练在小程序中只能查看排班，请假和调整时间由前台在[日程](./schedule#修改教练排班)中操作 |

## 闭馆

<Shot src="img/admin/settings-closures.webp" alt="闭馆" />

节假日或场馆维护时，可以按日期或时间段添加闭馆。闭馆期间所有教练都不开放预约。

如果闭馆时间内已有预约，系统会列出这些课程。课程不会自动取消，请在[预约](./bookings#场馆取消)中逐一改约或取消。已经开始的闭馆可以“提前结束”。

## 支付

<Shot src="img/admin/settings-payment.webp" alt="支付设置" />

| 设置 | 说明 |
| --- | --- |
| 单次付费 | 学员预约时直接付款 |
| 课时包 | 学员可以在小程序中购买课时包 |
| 体验课 | 关闭后学员无法预约体验课 |
| 每人体验课次数 | 每位学员最多可以预约的体验课次数，默认 1 次 |
| 支付时限 | 下单后超过这个时间仍未支付，订单自动取消并释放时段，默认 10 分钟 |

单次付费和课时包都关闭后，学员只能使用已有的课时包预约。

## 签到

<Shot src="img/admin/settings-attendance.webp" alt="签到设置" />

| 设置 | 说明 |
| --- | --- |
| 学员扫码签到 | 学员在课前 30 分钟起，可以用小程序扫描前台的签到码签到，详见[今日签到](./today#签到码) |
| 教练点名 | 教练在小程序中记录学员到课或缺席 |

无论如何设置，前台都可以随时在“今日”页签到和更正。签到不影响扣课和收款，课时包的课时在预约时就已扣除。

## 课时费

<Shot src="img/admin/settings-pay.webp" alt="课时费设置" />

| 设置 | 说明 |
| --- | --- |
| 学员缺席 | 课程结束时学员仍未到场，是否为教练计课时费 |
| 学员逾时取消 | 学员超过免费取消时限才取消，是否为教练计课时费 |

已结束的课程照常计入，场馆取消的课程不计入。课时费标准在[教练类别](./coaches#教练类别)中设置，月度结算详见[教练课时费](./coach-pay)。

## 协议与隐私

| 设置 | 说明 |
| --- | --- |
| 用户协议 | 留空则使用内置协议。学员首次预约或购买前需要同意 |
| 主体名称 | 需要与小程序后台登记的主体一致，会写入隐私政策。留空则使用场馆名称 |
| 隐私联系方式 | 用于处理个人信息问题的电话或邮箱。留空则使用场馆电话 |

修改设置会记入[操作记录](./action-log)。
