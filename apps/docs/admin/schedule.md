# 日程与排班

“日程”页以时间轴展示一天内每位教练的排班和课程，是排课、代约和调整排班的主要入口。

<Shot src="img/admin/schedule.webp" alt="日程" />

## 看懂日程

- 每一行是一位教练，横轴是时间。
- **浅色背景**是教练的排班时间，学员可以在其中预约；**斜线**表示请假或闭馆。
- **色块**是已有的课程，显示开始时间、学员和签到状态；小班课显示报名人数。
- 设置了球台数时，顶部会多出“球台”一行，显示每个时段已用的球台数量。

使用顶部的“前一天”“后一天”或日期选择器切换日期；按教练类别（级别）筛选，或搜索教练姓名。

::: warning 冲突提醒
以下课程需要您处理时，页面顶部会提示“有 N 节课需要改约或取消”：

- 落在教练请假或闭馆的时间里；
- 不在教练的排班里，例如教练在小程序中缩短了每周时间，或取消了有课的加班；
- 教练已停用。

点击“查看”可看到每节课及其原因，点击后跳到当天逐一处理。课程不会自动取消，请改约或取消。落在请假或闭馆里、或教练已停用的课程，学员在开课前可以随时免费取消。不在排班里的课程，如果已和教练确认照常上课，可点击该课程后的“已与教练确认”，课程保留在原时间，不再提示，学员不会收到改约消息。如果这节课在您打开列表后已被其他人改约或取消，页面会提示“这节课已有变化，请刷新后再看”并刷新列表，课程不会被改回原时间。您在[代约](./book)或改约时确认过的排班外时间也不会被提示。
:::

## 查看和处理一节课

点击课程色块，弹出这节课的信息：

- 修改签到状态；
- 点击“改约”或“场馆取消”；
- 点击“查看课程详情”打开完整的[课程详情](./bookings#课程详情)。

<Shot src="img/admin/schedule-lesson.webp" alt="点击课程后的操作" />

## 在空白处代约

在教练排班中的空白处点击，可以直接为学员预约这位教练在这个时间的课，详见[代约](./book)。

## 修改教练排班

点击左侧的教练姓名，打开这位教练的排班：

<Shot src="img/admin/schedule-hours.webp" alt="教练的排班" />

### 每周时间

1. 为每一天设置一个或多个时间段，点击“添加”增加时间段，点击“删除”移除。不设置的日子显示为“不接课”。
2. 选择“生效日期”。
3. 点击“保存每周时间”。

改动从生效日期起算，已约的课不受影响。结束时间 00:00 表示当天 24 点。

### 请假和加班

在同一窗口的“请假和加班”中：

- **请假**：选择全天（可跨多天）或某天的时间段。请假后这段时间不再开放预约，已约的课程不会自动取消，保存时会列出受影响的课程，请改约或取消。
- **加班**：在每周时间之外临时开放的时间，不能跨到第二天。
- 点击记录右侧的“取消”可以撤销；进行中的请假可以“提前结束”。取消已有课程的加班时，这些课程会保留，窗口顶部会列出它们，请改约或取消。

教练也可以在小程序中自行设置排班和请假，除非您在[设置](./settings#排班)中关闭了“教练自己排班”。场馆整体的闭馆在设置中管理。
