# 在手机上使用

管理后台也可以在手机浏览器中使用，方便前台在场地内签到和代约。在手机上打开与电脑相同的网址并登录即可，页面会自动切换为手机布局。

## 与电脑版的区别

- 点击左上角的菜单按钮打开功能菜单，点击任一页面后菜单自动收起。
- 顶部的放大镜用于搜索学员。手机上没有快捷菜单。
- 列表以卡片显示，每张卡片包含一条记录的全部信息。筛选条件收在“筛选”按钮中。
- 编辑页顶部有“编辑”和“预览”切换，可以查看修改后在小程序中的样子。

## 常用操作

<Shots>
  <Shot src="img/admin/phone-today.webp" alt="手机上的今日签到" phone />
  <Shot src="img/admin/phone-bookings.webp" alt="手机上的预约" phone />
</Shots>

- **签到**：打开“今日”，在学员的卡片上签到，误操作时点击“撤销”。详见[今日签到](./today)。
- **代约和前台建档**：在“今日”页顶部点击对应按钮，详见[为学员代约](./book)。
- **出示签到码**：在“今日”页点击“签到码”，请学员用小程序扫码。
- **查看预约**：在“预约”中按日期和学员查找，也可以直接修改签到状态。

::: tip 建议
排课、报表、设置等内容较多的页面，建议在电脑上操作。
:::
