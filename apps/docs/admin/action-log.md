# 操作记录

操作记录记录每位员工在后台进行的重要操作，便于核对和追溯。日志只能查看，不能修改或删除。本页需要“管理员”角色。

<Shot src="img/admin/action-log.webp" alt="操作记录" />

## 记录的内容

| 类别 | 操作 |
| --- | --- |
| 预约 | 代约、场馆取消、场馆改约、修改签到 |
| 排班 | 修改每周时间、添加和删除请假或加班（包括闭馆） |
| 小班课 | 排小班课、修改和取消小班课 |
| 点评 | 隐藏和恢复课后点评 |
| 课时包 | 前台售卖、赠送课时、延长有效期 |
| 退款 | 同意、拒绝、重试、按微信支付更新退款状态、线下退还 |
| 发票 | 开票、拒绝、确认开票后退款 |
| 订单 | 支付异常标为已处理 |
| 价格 | 课程价格、课时包价格、教练类别价格和课时费，确认和撤销确认月度课时费 |
| 学员 | 前台建档、修改学员信息和档案、删除学员 |
| 员工 | 新增员工、修改姓名、角色和密码 |
| 其他 | 修改设置、课程的预约规则、导出数据 |

教练在小程序中进行的操作（例如点名、编辑学员档案）不记入操作记录。

## 查找记录

- 按日期范围筛选；
- 在搜索框中输入内容或学员姓名；
- 按员工或操作类别筛选。排班和小班课的记录在“全部操作”中查看。

每条记录显示时间、员工、操作、内容，以及涉及的学员和金额。点击学员姓名可以打开学员详情。
