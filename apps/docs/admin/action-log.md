# 操作记录

操作记录记录每位员工在后台进行的重要操作，以及教练在小程序中对课程和排班的操作，便于核对和追溯。日志只能查看，不能修改或删除。本页需要“管理员”角色。

## 记录的内容

| 类别 | 操作 |
| --- | --- |
| 预约 | 代约、场馆取消、场馆改约、修改签到 |
| 排班 | 修改每周时间、添加、删除和提前结束请假或加班（包括闭馆） |
| 小班课 | 排小班课、修改和取消小班课 |
| 点评 | 隐藏和恢复课后点评 |
| 课时包 | 前台售卖、赠送课时、延长有效期、前台退课时包 |
| 退款 | 同意、拒绝、重试、按微信支付更新退款状态、线下退还、标为已另行退款 |
| 发票 | 开票、拒绝、确认开票后退款 |
| 订单 | 支付异常标为已处理 |
| 价格 | 课程价格、课时包价格、教练类别价格和课时费，确认和撤销确认月度课时费 |
| 学员 | 前台建档、修改学员信息和档案、删除学员 |
| 员工 | 新增员工、修改姓名、角色和密码 |
| 其他 | 修改设置、课程的预约规则、导出数据 |
| 教练操作 | 教练在小程序中取消课程、改约、修改每周时间、添加、删除和提前结束请假或加班 |

教练在小程序中的点名和编辑学员档案不记入操作记录。保存与原来相同的每周时间、重复提交同一请假不会重复记录；已开始的请假或加班被删除时，记为“提前结束”，并显示剩余的时间段。

## 查找记录

- 按日期范围筛选；
- 在搜索框中输入内容或学员姓名；
- 按员工、教练或操作类别筛选。

每条记录显示时间、操作人、操作、内容，以及涉及的学员和金额。教练的操作在操作人后标注“（教练）”。内容中的日期不在今年时会显示年份。点击学员姓名可以打开学员详情。
