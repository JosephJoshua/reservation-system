# 小班课

小班课是多位学员同上的课程，例如周末少儿班。场馆先排好场次，学员按场次报名。

## 准备工作

1. 在[课程](./courses)中新建课程，“上课人数”填写大于 1 的数字，即为小班课。可以设置最低开班人数和每人价格。
2. 在[教练](./coaches)中，让授课教练教这门课。

## 排小班课

<Clip src="video/admin-group-class.mp4" title="一次排好一段时间内的小班课" />

1. 在“日程”页点击“排小班课”。
2. 选择教练和课程。
3. 选择日期范围，勾选星期几上课。
4. 填写开始时间，多个时间用逗号分隔，例如 `09:00, 10:30`。
5. 填写每节人数。
6. 点击“创建 N 节”。

<Shot src="img/admin/group-new.webp" alt="排小班课" />

与该教练已有的课重叠、或在请假和闭馆中的时间不会被创建。

## 管理一节小班课

在日程中点击小班课，可以：

- 查看已报名的学员，并为学员签到、改约或取消；
- 点击“代约”为学员报名；
- 修改每节人数；
- “停止报名”或重新“开放报名”；
- “取消整节”：所有学员收到全额退款或退回课时，需填写取消原因（学员可见）；
- 没有学员报名时，可以直接删除这节课。

::: info 最低开班人数
设置了最低开班人数的课程，到免费取消截止时如果报名人数不足，整节课会自动取消并退款，学员会收到通知。
:::

教练在小程序中可以查看名单和点名，但不能调整名单或取消小班课。
