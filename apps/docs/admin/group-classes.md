# 小班课

小班课是多位学员同上的课程，例如周末少儿班。场馆先排好场次，学员按场次报名。

## 准备工作

1. 在[课程](./courses)中新建课程，“上课人数”填写大于 1 的数字，即为小班课。可以设置最低开班人数和每人价格。
2. 在[教练](./coaches)中，让授课教练教这门课。

## 排小班课

<Clip src="video/admin-group-class.mp4" title="一次排好一段时间内的小班课" />

1. 在“日程”页点击“排小班课”。
2. 选择教练和课程。
3. 选择日期范围，勾选星期几上课。
4. 填写开始时间，多个时间用逗号分隔，例如 `09:00, 10:30`。
5. 填写每节人数，不能超过课程的“上课人数”。
6. 点击“创建 N 节”。

<Shot src="img/admin/group-new.webp" alt="排小班课" />

开始和结束时间须为 5 分钟的整数倍。如果其中任何一节与该教练已有的课重叠，或落在请假和闭馆时间里，整批都不会创建，系统会提示冲突的场次。请调整日期、星期或时间后再创建。

## 管理一节小班课

在日程中点击小班课，可以：

- 查看已报名的学员，并为学员签到或取消预约（小班课不提供改约，需要换场次时请取消后重新代约）；
- 点击“代约”为学员报名；
- 修改每节人数；
- “停止报名”或重新“开放报名”；
- “取消整节”：已付款的学员收到全额退款或退回课时，尚未付款的学员的预约直接关闭，需填写取消原因（学员可见）；
- 没有学员报名时，可以直接删除这节课。

::: info 最低开班人数
设置了最低开班人数的课程，到免费取消截止时如果报名人数不足，整节课会自动取消并退款，学员会收到通知。
:::

教练在小程序中可以查看名单和点名，但不能调整名单或取消小班课。
